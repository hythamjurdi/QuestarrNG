# RSS feeds

Open **Discover → RSS** to review game releases from configured feeds. Items
include the feed's article link and a suggested game match. Open the game to
review it or follow the link to the feed source.

Choose **Manage Feeds** to add a feed by name and URL, enable or disable a feed,
or remove it. Disabled feeds are skipped. QuestarrNG refreshes enabled feeds
after startup and every hour; choose **Refresh Feeds** to run one immediately.
Overlapping refresh requests share the same run.

RSS is a discovery view. To search indexers or send a release to a downloader,
use the game's regular [search and acquisition flow](INDEXERS.md).
