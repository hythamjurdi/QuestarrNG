Items reviewed

- PR #239 is superseded by the current migration architecture. The application
  runs its own versioned SQLite/PostgreSQL migrations on startup and uses the
  existing structured logger; production does not invoke drizzle-kit.
- Issues #240 and #241 are verified. The container starts the compiled server,
  startup migrations no longer depend on `drizzle-kit push`, the migration
  module imports the exported logger, and the reported cron type errors are
  absent from the production TypeScript build.
- Issue #242 is verified against upstream PR #276. qBittorrent can receive a
  torrent file fetched by Questarr when the downloader cannot reach the
  indexer URL. If the request is accepted but the torrent is not confirmed,
  Questarr returns the correlation tag and the UI shows “Checking qBittorrent”
  with a warning to check the client before retrying. Free-space lookup falls
  back to qBittorrent server-state data.
- PR #243 is verified: IGDB fallback word queries run concurrently, the
  sanitizing regexes are compiled once, and the five-request cap is respected.
- PR #244 is verified: NotificationItem is a full-width semantic button with
  `type="button"`, providing native keyboard activation.
